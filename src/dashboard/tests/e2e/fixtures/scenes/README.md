# Fictional camera scenes

What a camera shows on the e2e fake backend and in the README captures: live frames, tile stills,
detection thumbnails and snapshots. Never real home footage, never an identifiable face.

Every file is a public-domain dedication (CC0 1.0), so it is redistributed without attribution
constraints. Each was cropped to 16:9, downscaled to 1024 x 576 and re-encoded without its metadata.
Add a scene only with a licence as free, and record it here.
