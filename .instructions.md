# Vyzio — Instructions de Développement

## Contexte du Projet

**Vyzio** est une solution de surveillance domestique **autonome, résiliente et privacy-first**, en phase de conception. L'objectif est de fournir une reconnaissance faciale IA locale sans dépendre de services cloud tiers pour le traitement des images.

### Vision Core
- Vos images restent chez vous (local-first, offline-first)
- Reconnaissance faciale IA embarquée
- Notifications intelligentes avec contexte (nom, visage inconnu)
- Compatible avec caméras IP existantes (RTSP/ONVIF)
- Stockage local des enregistrements

### Trois Modèles de Déploiement
1. **DIY** — Open Source, sur machine personnelle (PC, NAS, serveur)
2. **Vyzio Hub** — Mini-PC pré-configuré, clef-en-main
3. **Vyzio Cloud** — Abonnement mensuel, sans matériel

### Engagements
- **Privacy by design** — IA locale, zéro transmission d'images sans consentement
- **Transparence** — Code source ouvert, audit possible
- **Résilience** — Fonctionne sans internet
- **Interopérabilité** — Pas de vendor lock-in
